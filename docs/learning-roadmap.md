# Learning Roadmap

## Principle

每个案例都按同一个节奏学习：

1. 跑通原始功能。
2. 画出输入、处理、输出。
3. 删除一小块代码，再自己补回来。
4. 换成自己的业务场景。
5. 写 README、截图、复盘。

## Stage 1: RAG Foundation

目标：理解 PDF 问答系统的完整链路。

需要掌握：

- PDF 读取
- 文本切分
- Embedding
- 向量数据库
- Retriever
- Prompt
- LLM 回答
- 来源引用

完成标准：

- 能上传一个 PDF 并提问。
- 回答中能显示来源片段。
- 能解释为什么需要 chunk 和 embedding。
- 能说明系统如何降低幻觉。

## Stage 2: Data Analysis Agent

目标：让用户上传 CSV 或 Excel，用自然语言进行分析。

需要掌握：

- 文件解析
- Pandas 基础
- LLM 生成分析步骤
- 图表生成
- 分析报告输出

完成标准：

- 能回答数据字段含义、统计指标和趋势问题。
- 能生成至少一种图表。
- 能输出简短分析结论。

## Stage 3: Web Research Agent

目标：把网页搜索、内容提取和报告生成组合成一个研究助手。

需要掌握：

- 搜索工具调用
- 网页内容抽取
- 信息去重
- 多步骤总结
- Markdown 报告生成

完成标准：

- 输入一个主题，系统能生成结构化研究报告。
- 报告中保留来源链接。
- 能说明 Agent 的每一步做了什么。

## Stage 4: Agentic RAG

目标：把普通 RAG 升级成更可靠的 RAG。

需要掌握：

- 查询改写
- 相关性判断
- 低置信度拒答
- 检索失败重试
- 回答质量检查

完成标准：

- 能处理模糊问题。
- 找不到答案时不胡编。
- 能展示检索到的上下文。
