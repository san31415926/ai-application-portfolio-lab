## 可放入简历的表述

- 基于 Python 和 `pypdf` 实现 PDF 文本读取脚本，成功解析 AI 应用工程师示例 JD PDF，并输出页数、字符数和前 500 个字符，用于验证后续 RAG 流程。
- 设计 PDF 对话学习路线，将 PDF 读取、文本切分、Embedding、向量数据库检索、提示词回答和来源引用拆成可执行任务卡，降低 RAG 项目实现复杂度。
- 将基础 PDF 问答项目规划为 AI 求职资料知识库，面向岗位 JD、学习笔记和项目 README，目标输出技能要求、学习优先级、简历项目亮点和面试准备问题。

## 面试练习

| 问题 | 较好的回答思路 | 缺少的证明 |
| --- | --- | --- |
| 为什么 RAG 第一步是文档解析？ | 如果文本读取失败，chunk、Embedding、检索器都没有可靠输入；当前脚本先验证 PDF 能否提取干净文本。 | 增加正常 PDF 和失败/扫描 PDF 的示例。 |
| 为什么要切 chunk？ | 长文档不能直接塞进上下文；chunk 让检索可以返回相关片段，同时控制成本和噪声。 | 完成任务 2，并比较不同切片大小。 |
| 如何减少幻觉？ | 只允许模型基于检索片段回答并展示来源；没有证据时拒答。 | 完成任务 5，并增加拒答示例。 |
| 这个项目下一步怎么做？ | 完成切片、Embedding、向量数据库和来源约束生成，再封装为 Streamlit 演示。 | 增加截图和示例问答。 |

## 换电脑继续

1. 复制或克隆这个项目仓库。
2. 将 `codex-skills/ai-career-portfolio-coach/` 复制到新电脑的 `~/.codex/skills/`。
3. 根据 `.env.example` 重新创建 `.env`，不要提交 API 密钥。
4. 在 Codex 中打开项目，并发送：

```text
使用 $ai-career-portfolio-coach。先阅读 docs/career-profile.md 和 docs/codex-continuity.md，然后继续帮助我完成这个简历项目。
```
