# C 语言进阶：数组、指针和内存

## 数组

数组是一组连续存放的同类型数据。`int scores[5]` 可以保存 5 个整数。数组下标从 0 开始，最后一个元素是 `scores[4]`。

## 指针

指针保存的是地址。`int *p = &x;` 表示 `p` 指向变量 `x` 的地址。初学者可以把指针理解成“指向某个位置的路标”。

## 指针和数组的关系

数组名在很多表达式里会退化成首元素地址。理解这一点有助于看懂函数参数里的 `int arr[]` 和 `int *arr`。

## 常见错误

- 访问越界，例如 `scores[5]`。
- 使用未初始化指针。
- 返回局部变量地址。
- 忘记字符串末尾需要 `\0`。

## 练习

写一个函数，接收整数数组和长度，返回数组最大值。再尝试用指针遍历数组，理解地址如何移动。
