# C 语言入门：判断、循环和函数

## if 判断

`if` 用来根据条件执行不同代码。判断成绩是否及格可以写成 `if (score >= 60)`。条件表达式的结果只有真或假。

## for 循环

`for` 适合处理次数明确的重复任务，例如打印 1 到 100、遍历数组、统计总和。初学者要看懂三部分：初始化、循环条件、每轮更新。

## while 循环

`while` 适合条件不确定的场景，例如用户不断输入，直到输入 0 停止。使用 `while` 时要避免死循环，循环内部必须有机会改变条件。

## 函数

函数把一段逻辑封装成可以复用的模块。函数应该只做一件清楚的事情，例如 `add` 负责相加，`max` 负责找最大值。学习函数时要区分参数、返回值和函数调用。

## 练习

写一个函数 `int max(int a, int b)`，返回两个整数中较大的一个。再写一个循环，读入 5 个成绩并计算平均值。
