# C 语言入门：变量、类型和输出

## 学习目标

C 语言适合用来理解计算机如何存储和处理数据。初学者第一周不要急着写大项目，先理解变量、类型、表达式、输入输出和编译运行流程。

## 变量

变量是给数据起名字的一种方式。`int age = 18;` 表示创建一个整数变量 `age`，并把 18 放进去。变量名应该表达含义，例如 `score`、`price`、`count`，不要一开始就大量使用 `a`、`b`、`c`。

## 常见类型

- `int`：整数，例如人数、次数、编号。
- `double`：小数，例如价格、温度、平均值。
- `char`：单个字符，例如等级 `A`。
- `char[]`：字符数组，可以保存字符串。

## 输出

`printf` 用来输出内容。`%d` 输出整数，`%f` 输出小数，`%c` 输出字符。写代码时要注意格式占位符和变量类型对应。

## 练习

写一个程序，保存你的年龄、身高和姓名首字母，然后用 `printf` 打印出来。练习重点不是炫技，而是确认你知道变量、类型和输出之间的关系。
