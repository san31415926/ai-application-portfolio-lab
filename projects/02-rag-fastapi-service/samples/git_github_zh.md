# Git 和 GitHub 入门

## Git 是什么

Git 是版本控制工具，用来记录代码变化。它能帮助你回看历史、比较差异、创建分支和合并修改。

## 基本命令

- `git status`：查看当前状态。
- `git add`：把修改加入暂存区。
- `git commit`：保存一次历史记录。
- `git log`：查看提交历史。
- `git diff`：查看改了什么。

## GitHub 是什么

GitHub 是代码托管平台。作品集项目要写清楚 README、运行方式、截图和测试结果。

## 练习

创建一个新分支，修改 README，提交一次 commit，然后把分支推送到 GitHub。
