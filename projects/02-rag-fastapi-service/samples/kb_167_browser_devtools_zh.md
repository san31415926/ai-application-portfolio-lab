# 浏览器开发者工具

## 常用面板
Elements 用于查看 HTML 和 CSS，Console 用于查看日志和异常，Network 用于检查请求，Application 用于查看本地存储和缓存，Sources 用于断点调试 JavaScript。

## 网络排查
打开 Network 后重新操作页面，检查请求方法、状态码、请求载荷、响应 JSON 和耗时。如果请求没有发出，问题可能在事件绑定或前端校验；如果返回错误，再看服务端日志。

## 性能习惯
临时调试可以使用 `console.log`，提交前应清理无用日志。截图或复制错误信息时，要保留请求 URL、状态码和关键响应，方便复现问题。
