# Ollama 本地模型使用

## 作用
Ollama 提供了在本机运行和管理大语言模型的方式，应用可以通过本地 HTTP API 调用聊天和 Embedding 能力。模型文件、内存和推理速度会受电脑硬件影响。

## 常用流程
先使用 `ollama list` 查看模型，再用 `ollama run 模型名` 做交互测试。应用中要配置正确的 `OLLAMA_BASE_URL` 和模型名称，并在服务不可用时提供降级方案。

## 使用边界
本地模型适合隐私数据、离线演示和学习部署流程，但小模型可能在复杂推理、长文本和专业知识上能力有限。RAG 只能补充上下文，不能弥补所有推理能力差距。
