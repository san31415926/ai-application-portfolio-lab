# Python 入门：变量、列表和字典

## 变量

Python 变量不需要提前声明类型，写 `name = "Alice"` 就能保存字符串。变量名要有含义，推荐使用小写加下划线，例如 `user_name`。

## 列表

列表用来保存一组有顺序的数据。`scores = [90, 85, 72]` 保存三个成绩。可以用 `scores[0]` 取第一个元素，也可以用 `for score in scores` 遍历。

## 字典

字典用键值对保存信息。`student = {"name": "Li", "score": 90}`。当你需要用名字查值时，字典比列表更合适。

## 练习

写一个成绩统计程序：保存多个学生的姓名和成绩，计算平均分，找出最高分学生，并打印结果。
