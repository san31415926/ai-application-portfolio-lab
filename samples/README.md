# Sample Materials

这些是练习 `Project 01: Chat With PDF` 用的模拟素材。

素材不是最终项目成果，只是为了让你在没有真实 PDF 的时候，也能马上练习：

- PDF 读取
- 文本切分
- 向量检索
- 基于来源回答

## Files

- `source/ai_application_engineer_jd.md`: 模拟 AI 应用工程师岗位 JD。
- `source/rag_learning_notes.md`: 模拟 RAG 学习笔记。
- `pdf/ai_application_engineer_jd.pdf`: 由脚本生成的练习 PDF。

## Regenerate PDF

```powershell
python scripts/make_sample_pdf.py
```
